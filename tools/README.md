# tools — 자료를 만드는 연장들

**이 폴더는 저장소 안에 있어야 한다.** 2026-08-28에 이 연장들이 임시 폴더에 있다가
시스템 청소로 통째로 사라졌다. 실린 자료는 무사했지만 만드는 법이 없어졌다.
연장을 잃으면 자료를 고칠 수 없다.

## harvest_overture.py — 세계 전체를 받아 칸으로 쪼갠다

```bash
pip install duckdb
python tools/harvest_overture.py            # 1단계(받기) + 2단계(쪼개기)
python tools/harvest_overture.py --pull     # 받기만
python tools/harvest_overture.py --shard    # 쪼개기만 (이미 받아 둔 것으로)
python tools/harvest_overture.py --top 40   # 곳 수 많은 40개국만
```

**되감기가 된다.** 이미 받아 둔 타일은 건너뛴다. 중간에 멈춰도 한 시간을 잃지 않는다.
받은 타일은 `.harvest/` 아래 남는데, 그 폴더는 git이 무시한다 (수십 GB가 될 수 있다).

### 왜 이렇게 생겼나

- **10°짜리 타일 648장.** 985만 줄을 한 번에 파이썬에 들면 몇 GB다. Overture 파일은
  지리 순으로 놓여 있어서 타일 조건이 읽을 조각을 알아서 줄여 준다 — 바다 타일은 1초다.
- **나라마다 격자가 다르다.** 0.25°짜리 칸 하나가 영국 시골에서는 알맞지만 방콕에서는
  2.7 MB가 되고, 그걸 검색 한 번에 내려받게 된다. 나라마다 칸에 500곳쯤 들어가도록
  가장 성긴 격자를 골라 쓴다.
- **칸 파일은 압축 형식(v3).** 줄마다 되풀이되던 좌표 앞자리와 업종 이름을 뺐다.
  칸이 기준점을 한 번 밝히고, 집마다 어긋난 만큼만 정수로 적고, 업종은 번호로 가리킨다.
  서울 76,260곳에서 5.79 MB → 4.28 MB (26% 감소). 브라우저가 `regExpand()`로 편다.
- **정부 명부가 나라 전체를 덮는 곳은 건너뛴다** (영국·프랑스·덴마크·홍콩).
  같은 집이 두 번 나오지 않게. 미국처럼 일부만 덮은 곳은 실어 두고,
  겹치는 것은 검색할 때 정부 쪽을 남기고 버린다.
- **confidence 0.2에서 자른다.** 0.2~0.5 구간을 표본으로 열어 보니 쓰레기가 아니라
  인도네시아·브라질의 동네 밥집이었고 90%가 주소를 갖고 있었다. 그래서 안 버린다.

## 잃어버렸다가 다시 쓰지 않은 것들

`socrata.py`(미국·캐나다 도시 수확기)와 `clean.py`(좌표 검증)는 같은 사고로 사라졌다.
그것들이 만든 자료는 이미 실려 있어서 급하지 않다. 다시 필요해지면
`docs/place-registries.md`의 2단계 기록에 무엇을 어떻게 했는지 전부 적혀 있다 —
특히 **남의 지오코딩을 믿지 말 것**(댈러스는 식당의 21.8%를 댈러스 밖에 찍었다).
