배율마다 보여줄 것을 바꾼다
별 수천 개를 한 화면에 다 뿌리면 지구본이 죽처럼 됩니다.
규칙은 하나 — 배율이 올라갈수록 개수는 줄고 이름은 늘어난다.
지구본 — 대륙이 보이는 배율
보여줄 것 덩어리와 개수, 내 여정선, 국가 라벨
감출 것 개별 별, 식당 이름, 등급 배지
국가 — 나라 하나가 화면을 채울 때
보여줄 것 도시별 덩어리와 개수, 진행률 (4/12)
감출 것 아직 개별 별 이름
도시 — 여기가 전환점
보여줄 것 개별 별, 다녀온 곳은 채워진 점, 안 간 곳은 빈 점
감출 것 국가 라벨 (이제 방해물)
↓ 이 지점에서 지구본이 손을 떼고 로컬 지도가 받는다
거리 — 진짜 지도
보여줄 것 길 이름, 식당 이름표, 도장 버튼
감출 것 여정선 (이 배율에선 의미 없음), 진행률
항상 보이는 것 / 절대 안 보이는 것
항상 — 내 진행률, 출처와 최종확인 날짜
절대 안 함 — 전체 랭킹, 낯선 사람 피드, 팔로워 수 (기획서 §8.2)
개발용이라 제품에선 끔 — FPS · 국가 수 · 경계 정밀도 표시
